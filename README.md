# joey-ashley.github.io

A static site, served by GitHub Pages from `main`. No build: `.nojekyll` tells Pages to publish the files as they are.

| File | Page |
| --- | --- |
| `index.html` | Home |
| `lab.html` | How I run the lab |
| `lab-architecture.html` | Architecture: the site, state, DNS, and decision records |
| `lab-security.html` | Security: zones, the matrix, and the way in |
| `resume.html` | Resume, summarized |
| `404.html` | Served by Pages when a path does not exist |
| `style.css` | The one stylesheet, with a print layout for the resume |
